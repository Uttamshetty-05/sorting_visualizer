# 🔢 Sorting Algorithm Visualizer

An interactive web-based **Sorting Algorithm Visualizer** that helps users understand how different sorting algorithms work through real-time visual animations. This project demonstrates fundamental sorting techniques in an engaging and educational way.

👉 **Live Demo:**  
https://uttamshetty-05.github.io/sorting_visualizer/

---

## 📌 Features
- Real-time visualization of sorting algorithms  
- Step-by-step animation of sorting process  
- Easy-to-use interactive interface  
- Helps beginners understand algorithm flow clearly  
- Multiple sorting algorithms supported:
  - Bubble Sort  
  - Selection Sort  
  - Insertion Sort  

---

## 🛠️ Technologies Used
- HTML  
- CSS  
- JavaScript  

---

## 🎯 Project Objective
This project was developed to:
- Understand sorting algorithms practically  
- Visualize algorithm working for better learning  
- Improve frontend development skills  
- Practice DOM manipulation and animations  

---

## 🚀 How to Run Locally
1. Clone the repository:
   git clone https://github.com/Uttamshetty-05/sorting_visualizer.git

2. Open the project folder.

3. Run `index.html` in your browser.
